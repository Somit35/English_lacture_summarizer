# English Lecture Summarizer

A Python application that converts English lectures into text and creates concise summaries.

## Features

- Summarize lectures from YouTube URLs
- Transcribe audio recordings
- Convert speech to English text
- Generate short summaries
- Save summarized lecture notes

## Technologies Used

- Python
- Faster-Whisper
- yt-dlp
- FFmpeg

## Installation

Install Python dependencies:

```bash
pip install -r requirements.txt
```

Install FFmpeg using your operating system's package manager.

## How to Run

```bash
python lecture_summarizer.py
```

Follow the instructions displayed by the application.
